The Fourier transform is a very important tool that is used in math and physics. It's able to break down complex waves or signals into individual base freqeuncies meaning that we are able to transfer between the time and frequency domain. This is important as we are able to use an audio file and by using a Fourier transform we are able to identify what frequencies the audio is construced from. 

We can use the numpy libary to be able to utilize this tool by using `np.fft.fft()` which would then before the Fourier transform.
